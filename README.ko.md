## 📝 레포지토리 소개

- `Lecture-Notes/`에는 슬라이드 번호(`Lec01`\~`Lec10`)를 따른 강의 노트와 연습 문제, 풀이가 있습니다.
- `Coursework/`에는 단원별 C++ 실습 코드(`Lab01`\~`Lab10`), 프로그래밍 과제(`HW01`, `HW02`), 텀 프로젝트 2개가 있습니다.
- 모든 문서는 영어(`.md`)와 한국어(`.ko.md`) 파일이 짝을 이룹니다.
- 모든 코드는 C++17로 빌드하고 실행합니다.

> **🤖 AI 에이전트 활용**
> [Claude Code](https://claude.ai/download)를 노트 정리와 번역, 레포지토리 정리에 활용했습니다.

### 과목 개요

자료구조와 이를 다루는 알고리즘을 성능 분석과 시간 복잡도 중심으로 배우는 전공필수 과목으로, 영어로 진행된다. 교수자와 조교, 수업 일정, 평가, 수업 운영 규정, 진도는 [강의 정보 문서](Course-Information.ko.md)에 정리했다.
