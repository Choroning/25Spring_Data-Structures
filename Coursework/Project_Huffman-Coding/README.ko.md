## 개요

이 텀 프로젝트는 C++로 허프만 부호화 압축 도구를 구현한다. 허프만 부호화(Huffman coding)는 문자마다 나타나는 빈도에 따라 길이가 다른 이진 부호를 붙이는 무손실 데이터 압축 알고리즘이다. 자주 나오는 문자일수록 짧은 부호를 받으므로 전체 비트 수가 최소가 된다.

## 기능

- **빈도 분석:** 입력 텍스트에서 문자의 빈도를 자동으로 계산한다.
- **허프만 트리 구성:** 최소 힙 우선순위 큐를 이용해 최적의 접두어 없는(prefix-free) 부호 트리를 만든다.
- **부호화:** 생성한 부호표로 텍스트를 비트 문자열로 압축한다.
- **복호화:** 비트 문자열을 원래 텍스트로 되돌린다.
- **비트 단위 입출력:** 부호화한 비트를 바이트로 묶어 실제 압축처럼 저장한다.
- **압축 통계:** 원래 크기, 압축 후 크기, 압축률을 보고한다.

## 파일 구성

| 파일 | 설명 |
|:-----|:------------|
| `HuffmanTree.h` | 허프만 트리 클래스 선언 |
| `HuffmanTree.cpp` | 트리 구성, 부호 생성, 부호화와 복호화 |
| `PriorityQueue.h` | 최소 힙 우선순위 큐 (템플릿) |
| `PriorityQueue.cpp` | 우선순위 큐 소스 (템플릿 인스턴스화) |
| `BitStream.h` | 비트 단위 쓰기와 읽기 클래스 |
| `BitStream.cpp` | 비트 단위 입출력 구현 |
| `main.cpp` | 여러 예제로 압축과 복원을 보여 주는 데모 |

## 빌드와 실행

```bash
g++ -std=c++17 -O2 -o huffman HuffmanTree.cpp BitStream.cpp PriorityQueue.cpp main.cpp
./huffman
```

## 알고리즘

1. 입력 텍스트로 **빈도표를 만든다**.
2. 문자마다 그 빈도를 담은 **리프 노드를 만든다**.
3. **모든 노드를** 최소 우선순위 큐에 **넣는다**.
4. 노드가 하나 남을 때까지 다음을 **반복한다**.
   - 빈도가 가장 작은 노드 두 개를 꺼낸다.
   - 두 노드를 자식으로 하는 새 내부 노드를 만든다(빈도는 두 빈도의 합).
   - 새 노드를 우선순위 큐에 다시 넣는다.
5. 트리를 순회하며 왼쪽 가지에 0, 오른쪽 가지에 1을 붙여 **부호를 생성한다**.
6. 각 문자를 허프만 부호로 바꾸어 텍스트를 **부호화한다**.
7. 비트 문자열을 따라 트리를 내려가며 **복호화한다**.

## 복잡도

| 연산 | 시간 |
|:----------|:-----|
| 트리 구성 | $O(n \log n)$, $n$은 서로 다른 문자의 수 |
| 텍스트 부호화 | $O(m)$, $m$은 텍스트 길이 |
| 비트 복호화 | $O(k)$, $k$는 비트 수 |

## 예시

입력: `"ABRACADABRA"` (11글자 = 88비트)

| 문자 | 빈도 | 부호 | 사용 비트 |
|:-----|:-----|:-----|:----------|
| A | 5 | 0 | 5 |
| B | 2 | 10 | 4 |
| R | 2 | 110 | 6 |
| C | 1 | 1110 | 4 |
| D | 1 | 1111 | 4 |

압축 결과: 23비트 (압축률 73.9%)
