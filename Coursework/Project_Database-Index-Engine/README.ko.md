## 개요

이 텀 프로젝트는 C++로 B+ 트리 인덱스 엔진을 구현한다. B+ 트리는 관계형 데이터베이스(MySQL InnoDB, PostgreSQL, SQLite)가 인덱스에 쓰는 표준 자료 구조이다. 분기 계수를 최대로 키워 디스크 입출력을 최소화하고, 모든 데이터를 연결된 리프 노드에 두어 순차 접근을 지원하기 때문이다.

## 기능

아래의 시간 복잡도에서 $n$은 키의 수이고, $M$은 트리의 차수(템플릿 매개변수 `ORDER`)이다. 내부 노드는 자식을 최대 $M$개, 키를 최대 $M-1$개 가진다.

- **점 질의:** 키 하나를 $O(\log_M n)$에 탐색한다.
- **범위 질의:** 리프 연결 리스트를 따라 $[low, high]$ 안의 모든 키를 $O(\log_M n + k)$에 가져온다. 여기서 $k$는 돌려주는 키의 수이다.
- **삽입:** 키와 값의 쌍을 노드 자동 분할과 함께 $O(\log_M n)$에 삽입한다.
- **삭제:** 키를 언더플로 처리와 함께 $O(\log_M n)$에 삭제한다.
- **차수 설정:** 템플릿 매개변수로 분기 계수를 조정할 수 있다.

## 파일 구성

| 파일 | 설명 |
|:-----|:------------|
| `BPlusTree.h` | B+ 트리 클래스 선언 (템플릿, 차수를 매개변수로 받음) |
| `BPlusTree.cpp` | B+ 트리 구현 (삽입, 삭제, 탐색, 범위 질의) |
| `main.cpp` | 기본 연산과 성능 벤치마크를 보여 주는 데모 드라이버 |

## 빌드와 실행

```bash
g++ -std=c++17 -O2 -o index_engine BPlusTree.cpp main.cpp
./index_engine
```

## 설계 결정

1. **템플릿 차수 매개변수:** 분기 계수를 컴파일 시점에 조정할 수 있게 한다.
2. **리프 연결 리스트:** 효율적인 범위 질의와 순차 탐색을 지원한다.
3. **리프 분할의 복사 후 올림(copy-up):** 새 리프의 첫 키를 복사하여 부모로 올린다.
4. **내부 노드 분할의 밀어 올림(push-up):** 가운데 키를 부모로 밀어 올린다.

## 복잡도

| 연산 | 시간 | 비고 |
|:----------|:-----|:------|
| 탐색 | $O(\log_M n)$ | 키 하나의 조회 |
| 삽입 | $O(\log_M n)$ | 분할이 일어날 수 있음 |
| 삭제 | $O(\log_M n)$ | 합병이 일어날 수 있음 |
| 범위 질의 | $O(\log_M n + k)$ | $k$는 결과의 수 |
