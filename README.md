## 📝 About This Repository

- `Lecture-Notes/` holds lecture notes, exercises, and solutions that follow the slide numbers (`Lec01`-`Lec10`).
- `Coursework/` holds the C++ lab code for each unit (`Lab01`-`Lab10`), the programming assignments (`HW01`, `HW02`), and two term projects.
- Every document comes as an English (`.md`) and Korean (`.ko.md`) pair.
- All code was built and run with C++17.

> **🤖 AI Agent Usage**
> [Claude Code](https://claude.ai/download) was used to organize and translate the notes and to restructure the repository, and the test drivers of the assignments were written with Claude Code.

### Course Overview

A required major course taught in English on data structures and the algorithms that operate on them, with an emphasis on performance analysis and time complexity. The instructor and TA, schedule, assessment, course policies, and progress are in the [course information document](Course-Information.md).
